🙋 Việc của BẠN

  • Nghĩ ý tưởng — demo tính năng gì, cho ai xem, thông điệp chính.
  • Viết brief — vài dòng mô tả kịch bản (có mẫu sẵn ở dưới).
  • Cung cấp tài khoản đăng nhập vào phần mềm demo.
  • Xem & góp ý — "chỗ này zoom to hơn", "đổi câu mở đầu"... nói bằng tiếng Việt bình thường.

🤖 Việc của AI

  • Mở & điều khiển phần mềm, quay lại thao tác thật.
  • Cắt, tua nhanh các đoạn chờ, ghép thành footage mượt.
  • Tạo giọng đọc tiếng Việt & trộn nhạc nền.
  • Dựng hiệu ứng (camera zoom, số liệu nổi bật) và xuất video MP4.
ℹ️ Nói ngắn gọn
Bạn là đạo diễn ra kịch bản và duyệt bản dựng. AI là ê-kíp kỹ thuật làm tất cả phần còn lại. Toàn bộ trao đổi bằng tiếng Việt, gõ vào khung chat như nhắn tin.
Phần 1

ACài đặt môi trường (chỉ làm 1 lần)

Đây là phần "cài công cụ" trên máy tính — hơi kỹ thuật một chút nhưng chỉ làm đúng một lần. Nếu ngại, bạn có thể nhờ bạn IT làm hộ khúc này. Đa số thời gian là ngồi chờ tải về. Máy dùng Windows 10/11.

💡 Bí quyết đỡ vất vả
Sau khi cài xong Claude Code (Bước 2), bạn có thể nhờ chính AI kiểm tra và cài nốt phần còn thiếu — chỉ cần gõ: "Kiểm tra giúp mình máy đã có đủ Node, Python, ffmpeg chưa, thiếu cái nào thì hướng dẫn mình cài."
1

Cài Visual Studio Code (VS Code)

Đây là "phòng làm việc" — nơi bạn sẽ trò chuyện với AI.

Tải bản cho Windows, mở file .exe, bấm Next → Next → Install → Finish. Xong.

⬇️ Tải VS Code
2

Cài trợ lý AI "Claude Code" & đăng nhập

Đây chính là trợ lý sẽ dựng video cho bạn.

a. Mở VS Code. Nhìn thanh dọc bên trái, bấm biểu tượng Extensions (bốn ô vuông xếp hình, hoặc nhấn Ctrl+Shift+X).

b. Gõ "Claude Code" vào ô tìm kiếm → chọn tiện ích của Anthropic → bấm Install.

c. Sau khi cài, bên trái xuất hiện biểu tượng Claude. Bấm vào, chọn Sign in và đăng nhập bằng tài khoản Claude của công ty (trình duyệt sẽ mở ra để xác nhận).

ℹ️ Chưa có tài khoản Claude?
Hỏi quản lý/IT để được cấp quyền truy cập Claude của công ty trước khi làm bước này.
3

Cài các công cụ nền: Node, Python, ffmpeg, Git

Bốn công cụ để AI quay phim, lồng tiếng và cắt ghép. Cài một lượt bằng cách dán lệnh.

a. Trong VS Code, mở Terminal: menu trên cùng Terminal → New Terminal (hoặc nhấn Ctrl+`). Một khung dòng lệnh hiện ra ở dưới.

b. Bấm nút Sao chép ở khối bên dưới, dán vào Terminal (chuột phải → Paste), nhấn Enter, rồi ngồi chờ nó tải & cài từng cái:

Dán vào Terminal — cài 4 công cụ
# Cài Node.js, Python, ffmpeg, Git bằng winget (có sẵn trên Windows)
winget install OpenJS.NodeJS.LTS
winget install Python.Python.3.12
winget install Gyan.FFmpeg
winget install Git.Git
▲ Lưu ý nhỏ
Nếu nó hỏi đồng ý điều khoản, gõ Y rồi Enter. Cài xong 4 công cụ, hãy đóng Terminal và mở lại (hoặc khởi động lại VS Code) để máy nhận công cụ mới.

Nếu máy báo "winget không tồn tại", tải tay từng cái ở đây (bản Windows, cài mặc định Next→Finish):

⬇️ Node.js (bản LTS) ⬇️ Python ⬇️ ffmpeg ⬇️ Git
💡 Với Python
Nếu cài tay, ở màn hình đầu tiên nhớ tích ô "Add Python to PATH" rồi mới bấm Install.
4

Tải dự án (repo) về máy

Lấy toàn bộ bộ khung dựng video về máy bạn.

Trong Terminal của VS Code, dán lệnh sau để tải dự án về ổ C:\:

Dán vào Terminal — tải dự án
cd C:\
git clone https://github.com/AnhPhanIndus/Hyperframe_demo_video_creation.git HyperFrames

Lần đầu tải, trình duyệt có thể bật lên bảo bạn đăng nhập GitHub — đăng nhập bằng tài khoản công ty cấp. Chờ tải xong (dự án khá nặng, vài phút).

Sau đó mở dự án: menu File → Open Folder → chọn thư mục C:\HyperFrames → Open. Nếu nó hỏi "Do you trust the authors?", chọn Yes, I trust.

5

Cho AI "con mắt & đôi tay": bật Playwright MCP

Playwright MCP là thứ giúp AI mở được trình duyệt và điều khiển phần mềm thật để quay footage.

Dán 3 lệnh sau vào Terminal, nhấn Enter sau mỗi dòng:

Dán vào Terminal — trang bị cho AI
# 1) Cho Claude Code khả năng điều khiển trình duyệt
claude mcp add playwright npx @playwright/mcp@latest

# 2) Tải trình duyệt cho việc quay phim
npx playwright install chromium

# 3) Cài bộ tạo giọng đọc tiếng Việt (miễn phí, không cần API key)
pip install edge-tts
💡 Kiểm tra AI đã "nghe lời" chưa
Mở khung chat Claude, gõ /mcp rồi Enter. Nếu thấy dòng playwright · connected là ngon. Lần đầu ra lệnh quay phim, nhớ nhắc AI cụm chữ "dùng Playwright MCP" để nó chắc chắn dùng đúng công cụ.

3

AI làm việc — bạn ngồi xem

AI sẽ đi qua 6 chặng. Bạn chỉ cần chờ & trả lời khi nó hỏi.

Đây là những gì AI làm (nó sẽ báo từng bước cho bạn theo dõi):

  • Mở & dò app — đăng nhập, tìm đúng các nút theo kịch bản. AI có thể hỏi lại bạn về tài khoản hoặc đường đi.
  • Quay footage — mở phần mềm thật ở chất lượng Full HD, thao tác & quay màn hình.
  • Cắt & tua nhanh — những đoạn chờ AI của phần mềm xử lý (có thể lâu 2–3 phút) sẽ được tua nhanh lại.
  • Tạo giọng đọc — đọc kịch bản tiếng Việt bằng giọng nữ.
  • Trộn nhạc nền — ghép giọng đọc với nhạc, cân âm lượng.
  • Dựng & xuất video — thêm camera zoom, số liệu nổi bật, rồi render ra file MP4.
▲ Kiên nhẫn ở 2 chỗ
(1) Lúc phần mềm chạy AI để trả lời có thể mất vài phút — bình thường, AI sẽ tua nhanh sau. (2) Bước xuất video (render) cũng mất vài phút. Cứ để máy chạy, đừng tắt.

Nhờ AI cho xem trước vài khung hình hoặc bản nháp:

💬 Gõ cho AI

Nhận thành phẩm

File video nằm sẵn trong dự án, mở lên là dùng được.

Video hoàn chỉnh là một file .mp4 nằm trong thư mục renders của project, ví dụ: Projects\[tên project của bạn]\renders\video_60s.mp4.

Bấm phải vào file trong VS Code → Reveal in File Explorer để mở thư mục, rồi copy/gửi file đi như bình thường (Zalo, email, đưa lên máy chiếu...).

✦Mẹo viết brief cho video "ăn tiền"

Chất lượng video phụ thuộc rất nhiều vào brief. Vài nguyên tắc đơn giản:

✅ Nên làm

  • Nêu rõ 3–5 con số quan trọng muốn khoe (AI sẽ làm nổi bật chúng).
  • Giữ độ dài ~60 giây — vừa đủ hấp dẫn, không lê thê.
  • Phiên âm từ tiếng Anh: AI → "ây ai", DxFactory → "đi-ếch phách-to-ri".
  • Mô tả tông giọng mong muốn: nữ, vui tươi, truyền cảm, có nhấn nhá.
  • Ghi rõ luồng thao tác theo thứ tự, kèm tài khoản demo.
  • Chỉ ra chỗ cần zoom nhấn mạnh (số liệu, câu trả lời của AI).

⛔ Nên tránh

  • Brief mơ hồ kiểu "làm cho hay vào" — AI sẽ phải đoán.
  • Nhồi quá nhiều tính năng vào 60 giây → rối, không đọng lại gì.
  • Quên cung cấp tài khoản đăng nhập → AI không quay được app.
  • Để nguyên keyword tiếng Anh → giọng đọc phát âm sai, nghe kỳ.
  • Dùng dữ liệu thật/nhạy cảm của khách hàng lên demo công khai.
